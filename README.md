# 🗺️ نشان - Neshan Maps Lite

 یک اپ‌لیکیشن وب سبک و سریع برای نقشه، جهت‌یابی و جستجو - **مخصوص دستگاه‌های قدیمی مثل iPhone 5s**

## ✨ ویژگی‌ها

✅ **جستجوی مکان‌ها** - جستجو کنید و نتیجه رو روی نقشه ببینید  
✅ **موقعیت من** - موقعیت فعلی و آدرس شما رو بدست بیاورید  
✅ **مسیریابی** - فاصله و زمان تخمینی بین دو مکان  
✅ **سازگار با دستگاه‌های قدیمی** - iOS 12+ پشتیبانی می‌کند  
✅ **واکنش‌پذیر** - روی تمام اندازه‌های صفحه کار می‌کند  
✅ **رایگان** - بدون تبلیغ یا اشتراک

## 🚀 شروع سریع

### 1️⃣ دریافت API Key

1. به [https://neshan.org](https://neshan.org) بروید
2. ثبت‌نام کنید (رایگان)
3. یک API Key برای وب ایجاد کنید

### 2️⃣ تنظیم API Key

`app.js` فایل رو باز کنید و این خط رو تغیر بدید:

```javascript
const NESHAN_API_KEY = 'web.YOUR_API_KEY'; // API Key خود را جایگزین کنید
```

### 3️⃣ آپ‌لود کنید

فایل‌ها رو روی یک هاست آپ‌لود کنید:

**گزینه‌های رایگان:**
- [Netlify](https://netlify.com) - drag & drop
- [Vercel](https://vercel.com)
- [GitHub Pages](https://pages.github.com)

### 4️⃣ باز کنید روی iPhone 5s

لینک هاست رو روی Safari باز کنید!

## 📱 سیستم‌های پشتیبانی‌شده

- ✅ iOS 12+ (iPhone 5s و بالاتر)
- ✅ Android 4.4+

## 📖 راهنمای استفاده

### جستجو
1. برو به تب "جستجو"
2. مکان رو تایپ کن (مثلاً: "فرودگاه امام")
3. روی "جستجو" کلیک کن
4. نتیجه رو از لیست انتخاب کن

### موقعیت من
1. برو به تب "موقعیت من"
2. روی "📍 موقعیت من" کلیک کن
3. اجازه دسترسی به موقعیت رو بده
4. موقعیت و آدرس نمایش داده می‌شود

### مسیریابی
1. برو به تب "مسیر"
2. "از کجا؟" و "به کجا؟" رو پر کن
3. روی "🚗 مسیر" کلیک کن
4. فاصله و زمان تخمینی دیده می‌شود

## 🛠️ تکنولوژی‌ها

- **OpenStreetMap** - داده‌های نقشه (رایگان)
